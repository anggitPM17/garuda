# 🛡️ Kebijakan Keamanan (Security Policy)

## Versi yang Didukung (Supported Versions)

Kami memberikan pembaruan keamanan untuk versi utama yang sedang aktif:

| Versi | Didukung | Catatan |
| --- | --- | --- |
| v67.0.0 / v0.1.0 | :white_check_mark: | Versi aktif utama Lapis 0 |
| < v67.0.0 | :x: | Versi legacy |

---

## 📩 Melaporkan Celah Keamanan (Reporting a Vulnerability)

**JANGAN membuat Issue publik di GitHub untuk celah keamanan yang sensitif!**

Jika Anda menemukan kerentanan keamanan pada compiler `grdc` atau runtime GVM:

1. Harap laporkan celah tersebut secara privat melalui email pemilik proyek atau kanal pelaporan privat GitHub Security Advisories.
2. Sertakan detail langkah-langkah untuk mereproduksi masalah, skrip contoh, serta dampak potensi keamanan.
3. Tim akan merespons laporan dalam waktu 48 jam dan memberikan estimasi waktu perbaikan secara transparan.

Terima kasih telah membantu menjaga keamanan ekosistem Garuda!
