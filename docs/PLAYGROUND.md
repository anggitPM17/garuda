# 🏟️ Stadion Garuda Web Playground Guide

Dokumen ini menjelaskan penggunaan **Stadion Garuda Web Playground** untuk menulis, mengompilasi, dan mengeksekusi sintaks kode Garuda `.grd` langsung di browser.

---

## 🚀 Penggunaan Web Playground

1. Buka file `site/playground.html` di browser web (misal: Chrome, Firefox, Edge).
2. Tulis atau modifikasi kode sintaks Garuda pada editor panel kiri:
   ```garuda
   modul Utama

   fungsi utama() ->
       cetak("Halo dari Garuda BEAM v67.0.0 di Browser! 🦅🇮🇩")
   rampung
   ```
3. Klik tombol **`⚡ Jalankan Kode (Run)`**.
4. Hasil kompilasi dan output eksekusi akan ditampilkan pada panel konsol di sebelah kanan.
