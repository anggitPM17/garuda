🦅 GVM IDENTITY SERVICE

🏠 Kembali ke Portal

🔐 Single Sign-On (SSO) & Central Identity Provider

GVM Identity Service (One Key Pass) adalah layanan otentikasi terpusat berbasis HMAC SHA-256 JWT untuk seluruh ekosistem Garuda BEAM. Cukup mendaftar satu akun untuk mengakses RICHAT Android, Stadion Garuda, dan Garuda Arena.

🌐 API Endpoints Specification

1. User Registration

POST https://richat.my.id/api/register

curl -X POST https://richat.my.id/api/register \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=pilot_pro&password=secret_password"

2. User Login & Token Generation

POST https://richat.my.id/api/login

curl -X POST https://richat.my.id/api/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=pilot_pro&password=secret_password"

Sample Response:

{
  "status": "ok",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "username": "pilot_pro"
}

3. Verify Token / User Identity

GET https://richat.my.id/api/me

curl -X GET https://richat.my.id/api/me \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>"

Sample Response:

{
  "status": "ok",
  "username": "pilot_pro",
  "role": "pilot"
}

💻 Integration Code Snippets

JavaScript / Fetch Client (Browser & Node.js)

async function loginToGVM(username, password) {
  const formData = new URLSearchParams();
  formData.append('username', username);
  formData.append('password', password);

  const res = await fetch('https://richat.my.id/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: formData.toString()
  });

  const data = await res.json();
  if (data.status === 'ok') {
    localStorage.setItem('garuda_jwt_token', data.token);
    console.log("Logged in as:", data.username);
  }
}

Kotlin / OkHttp Client (Android Client)

val formBody = FormBody.Builder()
    .add("username", "pilot_pro")
    .add("password", "secret_password")
    .build()

val request = Request.Builder()
    .url("https://richat.my.id/api/login")
    .post(formBody)
    .build()

client.newCall(request).enqueue(object : Callback {
    override fun onResponse(call: Call, response: Response) {
        val json = JSONObject(response.body?.string() ?: "{}")
        if (json.optString("status") == "ok") {
            val token = json.getString("token")
            saveJwtToken(context, token)
        }
    }
})
