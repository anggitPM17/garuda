# 🦅 Garuda Language Support for Visual Studio Code

Ekstensi resmi Visual Studio Code untuk Bahasa Pemrograman **Garuda** (`.grd`).

---

## ✨ Fitur Utama

- **Syntax Highlighting**: Pewarnaan kata kunci Nusantara (`modul`, `fungsi`, `rampung`, `tampa`, `cakra`, `yen`, `makro`), Atom (`:ok`), String, dan Operator.
- **Snippets**: Shortcut pembuatan template `modul`, `fungsi`, `makro`, `tampa`, `cakra`, dan `yen`.
- **Language Configuration**: Dukungan komentar `--`, pencocokan kurung `{}` `[]` `()`, dan penataan lipatan kode (*folding markers*).

---

## 🛠️ Instalasi Lokal

```bash
cp -r vscode-garuda ~/.vscode/extensions/garuda-lang
```
